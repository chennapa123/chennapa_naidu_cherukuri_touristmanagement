# Tourist Management System — Frontend (Starter Scaffold)

This is a starter scaffold for the **Tourist Management System** frontend:
React + Vite + Tailwind CSS, plus a JSON-server sample backend (`db.json`).

## Quick start

1. Install dependencies:
```bash
npm install
```

2. Start JSON-server (sample backend):
```bash
npm run json-server
```
This serves `db.json` at http://localhost:4000

3. Start the frontend:
```bash
npm run dev
```
Open the address shown by Vite (usually http://localhost:5173)

## What’s included
- `src/` — React app with pages and components
- `db.json` — sample JSON-server dataset (destinations, packages, bookings, users)
- Tailwind + PostCSS configs
- `services/api.js` — axios instance pointed at JSON-server

Fill out and extend the components and routes per your project requirements.
